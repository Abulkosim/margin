Margin

Claude Code and Codex usage in your menu bar

See remaining quota and reset times across multiple accounts, from the macOS menu bar or the Windows system tray.

Download for macOS Download for Windows

Free and open source · MIT · GitHub

What it does

  • Multiple accounts

    Finds existing Claude Code and Codex sign-ins. Add a configuration folder for each extra account.

  • Limits and resets

    Remaining percentage and reset countdown for session, weekly, and model-specific limits.

  • Last known usage

    When a request fails, the last reading stays visible with its age. Missing data stays unknown.

  • macOS and Windows

    One app for the menu bar and the system tray. Install updates from Settings when you choose.

How it works

Sign in with Claude Code or Codex as usual. Margin reads those existing OAuth sign-ins and asks each provider for your usage. No Margin account or hosted backend.

Read-only. Margin never writes to CLI credential files, rotates tokens, or spends reset credits. Tokens stay in the Rust process; the interface never sees them.

Privacy

No telemetry, analytics, or crash reporting. Margin connects only to:

  • api.anthropic.com Claude usage
  • chatgpt.com Codex usage
  • github.com updates, only when you ask

Details in PRIVACY.md and SECURITY.md.

Install

Builds don't carry an Apple or Microsoft publisher signature yet, so the system warns on first launch.

Full install notes

macOS 12+. Open the universal .dmg and move Margin to Applications. If macOS blocks it, go to System Settings → Privacy & Security → Open Anyway.

Windows x64. Run the -setup.exe. If SmartScreen warns, choose More info → Run anyway.

Margin is independent and not affiliated with Anthropic or OpenAI.
