# v0.12.0

2026-11-22 · [Download](https://github.com/Abulkosim/margin/releases/tag/v0.12.0)

- If your computer's clock was ahead and then corrected, alerts and the weekly digest no longer stay silent until the wrong time passes.
- If Margin quits partway through **Make active**, the next launch no longer swaps the two accounts' names, alerts or history.
- Alerts and `margin --line` name reset days the same way as the window: a reset six days away shows its weekday.
- Usage remaining in the window now rounds down, like the tray icon, so both show the same number.
- If a sign-in changes while Margin is closed, its readings are no longer added to the previous person's history.
- In menus, pressing Enter picks the option chosen with the keyboard, even if the pointer rests over the list (macOS).
- Easier to read: stronger contrast for small text and icons, dialogs that stand out in dark mode, focus rings that are never cut off, and layouts that fit narrow windows.
- If Margin can't connect at startup, the error shows once instead of twice.
- This release passed automated tests and builds on macOS and Windows but hasn't been checked by hand on a real Mac or Windows PC yet. If something looks wrong, use **Report a problem**.
