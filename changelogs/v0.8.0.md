# v0.8.0

2026-10-26 · [Download](https://github.com/Abulkosim/margin/releases/tag/v0.8.0)

- Statusline: `margin --line` now shows both providers with session and weekly usage remaining and the time until each resets, in fixed columns so the line never jumps, with colours when Claude Code runs it. It picks the account of the folder your terminal uses. `--short` keeps the old one-account line, `--all` lists every account. See [Command line](https://github.com/Abulkosim/margin#command-line).
- Weekly digest: one notification on Monday mornings with last week's lowest remaining per account, how many sessions ran out, and the busiest day. Off by default; turn it on in Settings → Notifications → Weekly digest.
- Balances: Codex cards show credits and the monthly credit limit, and Claude cards keep extra usage, in a Balance block under the limits. Named Codex limits such as Spark show as chips next to the weekly limit.
- Codex plans with a single weekly limit now show it as Weekly, not Session, in the popover, the tray, alerts and the statusline. Existing history and alerts carry over.
- Make active covers the Codex desktop app: it shares the CLI sign-in, so switching works, and Margin asks you to quit the app and its background helper first.
