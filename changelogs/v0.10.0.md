# v0.10.0

2026-11-05 · [Download](https://github.com/Abulkosim/margin/releases/tag/v0.10.0)

- Idle accounts: when a Claude Code token expires while you aren't using it, the account now says "Idle, last read 3h ago" instead of "Signed out", with the command that gets a new reading. Real sign-outs still say "Signed out".
- After a limit's reset time passes with no new reading, it shows "Reset 14:00, not read since" instead of the old percentage.
- If part of a provider's response can't be read, the limits that could be read stay visible, marked "Incomplete".
- Settings → Notifications has **Send test notification**. Margin retries a notification it couldn't submit and shows the failure there.
- The "Usage not updating" alert now also fires when an account's usage server can't be reached while your other provider reads fine.
- Margin offers **Start at login** once, so alerts keep running after a restart. On macOS it warns when the app isn't in Applications. "Launch at login" is now "Start at login".
- **Report a problem** in Settings opens a prefilled GitHub issue after you review it. It includes the version, OS, account counts and error kinds, and leaves out emails, account names, paths and tokens.
- Make active is labeled Beta until it has had more real-world testing.
- This release passed automated tests and builds on macOS and Windows but hasn't been checked by hand on a real Mac or Windows PC yet. If something looks wrong, use **Report a problem**.
