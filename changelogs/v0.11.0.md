# v0.11.0

2026-11-10 · [Download](https://github.com/Abulkosim/margin/releases/tag/v0.11.0)

- Margin now ships its own copy of the Inter font, so text looks the same on every Mac and PC, as in the screenshots.
- The keyboard focus ring is easier to see in light mode.
- Messages at the bottom of the window stay while you hover over or focus them, so there's time to press **Undo**, and screen readers announce them.
- Pressing Esc in **Add account** closes only the form and keeps what you typed.
- Clearer wording: "Reset alerts" and "Not updating alerts" in Settings, reset tooltips without seconds, and the same wording for errors throughout.
- With **History** closed, cards reload usage history about once an hour instead of on every refresh, so Margin does less work with many accounts.
- If a provider changes the letter case of your email, Margin keeps that account's usage history.
- Margin keeps only the five newest settings backups.
- Updated dependencies and a smaller app.
- This release passed automated tests and builds on macOS and Windows but hasn't been checked by hand on a real Mac or Windows PC yet. If something looks wrong, use **Report a problem**.
