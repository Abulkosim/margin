# v0.7.0

2026-10-26 · [Download](https://github.com/Abulkosim/margin/releases/tag/v0.7.0)

- Make active: switch which account `claude` or `codex` uses from Settings → Accounts. Margin swaps the sign-in of the default folder with the folder you choose, so both stay signed in, and keeps a backup. The account in the default folder shows an Active tag. Undo switches back. Codex must be closed first.
- Fast usage alerts: get an alert when a session or weekly limit uses 10, 20 or 30% within an hour, with the time it runs out at that rate. Off by default; turn it on in Settings → Notifications.
- Command line: `margin --line` prints one line for statuslines, such as the Claude Code status line, and `margin --json` prints every account's usage for scripts. Both read what Margin last saved and make no network requests. See [Command line](https://github.com/Abulkosim/margin#command-line).
- Claude accounts are read from the macOS Keychain before `.credentials.json`, the same order Claude Code uses, and folders with non-English characters in their path now match their Keychain item.
