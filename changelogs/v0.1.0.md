# v0.1.0

2026-10-16 · [Download](https://github.com/Abulkosim/usagebar/releases/tag/v0.1.0)

- First macOS and Windows app for Claude Code and Codex usage.
- Track multiple accounts from existing CLI sign-ins or added config folders.
- Show remaining session, weekly, and model quotas with reset countdowns.
- Keep the last successful reading visible when a refresh fails.
- Pin an account to the tray or show the account with the least quota left.
- Set the theme, refresh interval, usage reminders, and launch at login.
