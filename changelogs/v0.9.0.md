# v0.9.0

2026-11-02 · [Download](https://github.com/Abulkosim/margin/releases/tag/v0.9.0)

- Run-out warnings: a notification when a session, weekly or model limit is on pace to run out before it resets, with the time it runs out. On by default; Settings → Notifications.
- Usage not updating: a notification when an account can't be read for 30 minutes, so you know its alerts can't fire. On by default.
- An 80% or 95% alert also says when the limit runs out, if that's before it resets.
- The card's pace line uses the same forecast as the warnings, and weekly pace reads the last day and a half, including time away from the computer.
- Margin writes its settings file far less often while refreshing.
- A new sign-in in the same folder no longer adds readings to the previous person's history, and removing an account keeps its history if saving settings fails.
- History keeps saving after going back to v0.7 and forward again with Codex accounts.
- On macOS, Make active refuses a sign-in too long to pass safely to the Keychain instead of putting it on the command line.
