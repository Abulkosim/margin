# v0.8.2

2026-11-02 · [Download](https://github.com/Abulkosim/margin/releases/tag/v0.8.2)

- An account no longer shows as last known, or drops out of the tray's lowest-remaining pick, when only a model limit such as Opus has passed its reset time.
- Reset and fast usage alerts cover Codex plans whose limits are not 5 hours or 7 days, such as monthly limits.
- Changing plan no longer sends usage alerts you already got again.
- Usage history stays continuous when a provider reports the same reset time a few seconds apart, so history files stay small.
- After a sign-in changes during a refresh, Margin retries within seconds instead of waiting a full interval.
- On macOS, a Keychain item without a Claude sign-in falls back to `.credentials.json`.
- Make active is safer: restoring a backup refuses while Codex runs, a relaunch no longer makes a restore overwrite a newer sign-in, locks left by a crash are reclaimed, and an unreadable switch history is kept aside instead of overwritten.
- `margin` with a mistyped option such as `--jsno` prints the usage instead of starting the app.
