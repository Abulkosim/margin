# v0.4.0

2026-10-22 · [Download](https://github.com/Abulkosim/margin/releases/tag/v0.4.0)

- Find Claude accounts that were signed in with `CLAUDE_CONFIG_DIR` on macOS. Margin reads their Keychain entry; no `.credentials.json` is needed.
- Show "Signed out" with the exact command to run, and copy it with one click. Expired tokens no longer trigger a request.
- Refresh right after the Mac wakes from sleep.
- Keep accounts out of "needs attention" while a rate limit or retry is in progress and the last reading is still recent.
- Load settings even when one saved account is damaged, and add "Back up and reset settings" to the recovery screen.
- Request the Claude profile at most once an hour per account.
- Repository moved to `Abulkosim/margin`. Release files now carry GitHub build provenance; see [Verify a download](https://github.com/Abulkosim/margin#verify-a-download).
