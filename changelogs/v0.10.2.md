# v0.10.2

2026-11-10 · [Download](https://github.com/Abulkosim/margin/releases/tag/v0.10.2)

- **Start at login** keeps working after you move Margin. On macOS it follows the app once it runs from Applications; on Windows it follows the app when the old copy is gone.
- An alert or weekly digest that couldn't be shown before you quit Margin is shown after you reopen it, if it still applies. One that was already shown isn't repeated.
- A Claude model limit that the server sometimes sends malformed no longer repeats the same usage alert.
- An out-of-range reset time or limit length from a provider no longer breaks the popover for every account. Only that reading fails or loses that limit, and other accounts keep updating.
- If a session or weekly limit arrives without a percentage, the reading is marked **Incomplete** instead of looking complete.
- This release passed automated tests and builds on macOS and Windows but hasn't been checked by hand on a real Mac or Windows PC yet. If something looks wrong, use **Report a problem**.
